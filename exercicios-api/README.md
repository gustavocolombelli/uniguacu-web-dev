# Exercícios básicos — HTML, CSS e JavaScript com APIs

Abra cada arquivo `.html` direto no navegador (todos usam o `style.css` compartilhado e `fetch` com `async/await`). Nenhuma API exige chave.

| # | Arquivo | API | Conceito |
|---|---------|-----|----------|
| 01 | `ex01-cep.html` | ViaCEP | `fetch`, JSON, tratamento de erro |
| 02 | `ex02-formulario.html` | ViaCEP | máscara de input, preenchimento automático |
| 03 | `ex03-endereco-para-cep.html` | ViaCEP | busca inversa, lista com `map` |
| 04 | `ex04-estados-cidades.html` | IBGE | selects encadeados |
| 05 | `ex05-cachorro.html` | Dog CEO | imagem dinâmica, botão desabilitado |
| 06 | `ex06-cotacao.html` | AwesomeAPI | conversão e `toLocaleString` |
| 07 | `ex07-pokemon.html` | PokéAPI | card, `response.ok`, tecla Enter |
| 08 | `ex08-posts-filtro.html` | JSONPlaceholder | `filter` em tempo real |
| 09 | `ex09-feriados.html` | BrasilAPI | parâmetro na URL, formatar data |
| 10 | `ex10-historico-cep.html` | ViaCEP | `localStorage` |

Desafio extra: no ex. 01, desabilite o botão e mostre "Buscando..." durante a consulta.
