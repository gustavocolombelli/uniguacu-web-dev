Exercícios de Flexbox

Baseados nos exemplos de flex-box.html. Cada exercício mostra o ponto de partida (container ainda sem a propriedade pedida) e o enunciado do que fazer. Tente escrever o CSS sozinho antes de abrir a solução.

1. Ativando o Flexbox

O container abaixo tem três <div>, mas ainda sem display: flex — por isso continuam empilhadas. Adicione a propriedade que falta para colocá-las lado a lado.

.container {
  display: flex;
}
