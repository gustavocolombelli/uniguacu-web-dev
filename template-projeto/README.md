# Template de Projeto

Estrutura base para começar um projeto web (HTML + CSS + JS).

## Estrutura de arquivos

```
.
├── index.html              # página principal
└── resources/
    ├── css/
    │   └── style.css       # estilos
    ├── js/
    │   └── script.js       # scripts
    └── img/
        └── logo.svg        # imagens do projeto
```

## Como usar

1. Copie a pasta `template-projeto/` para o local do seu projeto.
2. Abra o `index.html` no navegador (ou use uma extensão como Live Server).
3. Edite `resources/css/style.css` para os estilos, `resources/js/script.js` para o comportamento, e adicione novas imagens em `resources/img/`.

Os caminhos no `index.html` já apontam para esses arquivos (`resources/css/style.css`, `resources/js/script.js`, `resources/img/logo.svg`), então basta manter essa organização de pastas.
